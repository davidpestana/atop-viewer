Install on Ubuntu / Debian

sudo apt install ./atop-viewer-VERSION-amd64.deb
atop-viewer

Replace VERSION with the downloaded release. The package depends on atop.

Other Linux distributions

chmod +x atop-viewer-VERSION-x86_64.AppImage
./atop-viewer-VERSION-x86_64.AppImage

AppImage needs no install step. Ensure atop and FUSE/libfuse2 are available on your distro.
