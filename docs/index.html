Atop Viewer

Visualiza logs diarios de atop: gráficas de sistema, modo en vivo, procesos y líneas temporales.

Descargar

Requiere atop instalado en el sistema (sudo apt install atop).

También en GitHub Releases.

Instalar en Ubuntu / Debian

sudo apt install ./atop-viewer-VERSION-amd64.deb
atop-viewer

Sustituye VERSION por la versión descargada. El paquete declara dependencia de atop.

Otras distribuciones Linux

chmod +x atop-viewer-VERSION-x86_64.AppImage
./atop-viewer-VERSION-x86_64.AppImage

AppImage no requiere instalación. Asegúrate de tener atop y FUSE/libfuse2 según tu distro.
